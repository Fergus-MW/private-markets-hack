6. Basis and boundary (what this review does not cover)

This review traces: every upload row back to a source GL row, and every code back to its mapping table. It does not vouch: no row was agreed to a bank statement, invoice, contract note or valuation report. The pack contains none, and the GL carries no document reference in any of its 43 source columns. An error introduced upstream of the GL export would pass every check in this memo.
